# 🇫🇷 FR
Ce dépot GitHub sert à stocker les modifications du site web CHAU'MUN, une association lycéenne visant à faire débattre des élèves venant de l'Europe et du monde entier tels que le font les délégués des Nations Unies. Chaque élève est associé à :
- un pays dont il doit défendre les intérêt ;
- un comité, un groupe de débat ;
- une problématique d'échelle mondiale.
